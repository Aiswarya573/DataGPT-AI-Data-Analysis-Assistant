# DataGPT – AI-Powered Data Analysis Assistant

## About

DataGPT is an AI-powered data analysis assistant that allows
users to upload CSV/Excel datasets and interact with their data
using natural language.

## Features

- CSV/Excel upload
- Data quality analysis
- AI-powered data Q&A
- Automatic visualization
- Automatic business insights
- Data Analyst Mode
- Follow-up conversations
- SQL Detective
- Anomaly detection
- Recommendation engine
- Calculation explanation

## Tech Stack

Python
Pandas
Streamlit
Plotly
SQLite
Gemini API
